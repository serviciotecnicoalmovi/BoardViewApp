# Repair Workspace

El Repair Workspace reúne un PDF de placa y un PDF de esquemático en una misma ventana.

## Flujo

1. Abrir **Herramientas → Repair Workspace**.
2. Seleccionar el PDF de placa y el PDF del esquemático.
3. Buscar una referencia, por ejemplo `U3500`.
4. Seleccionar un resultado para navegar a la página correspondiente.
5. Registrar una nota y su estado técnico.
6. Guardar la sesión como archivo `.bvrepair`.

El archivo de proyecto contiene rutas, páginas, notas, estados e historial. Los documentos originales nunca se modifican.
