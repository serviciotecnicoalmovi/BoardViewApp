# Estándares de código

- Nullable habilitado.
- Advertencias tratadas como errores.
- XML obligatorio en API pública.
- Dependencias mediante constructor.
- Ningún `TODO`, `NotImplementedException` o método vacío en entregas.
- Operaciones de E/S validan argumentos y propagan errores con contexto.
- Los módulos no acceden a controles WPF fuera de `BoardView.App` y `BoardView.Rendering`.
